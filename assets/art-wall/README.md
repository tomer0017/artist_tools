# Wall Studio interiors

Created for SketchyArtLab with the built-in OpenAI imagegen tool, 27 November 2026.
These are original generated photorealistic interiors and isolated furniture, not stock photographs or photographs of actual properties. No uploaded user artwork was used as input. No third-party stock assets or brand designs were requested.

`source-manifest.json` records the exact prompts and preserved source paths. Project runtime copies are the optimized WebP files in `public/images/art-wall/` (five rooms, four sofas). Sofa alpha is preserved; only transparent outer margins were trimmed. Artwork is composited separately in the browser. Room rendering uses the same centimetre scale for artwork and furniture; architectural background measurements are illustrative.
